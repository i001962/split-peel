# Proof Patrol Writers Room Process

Use this process for Proof Patrol brainstorming, premise selection, and short-script drafting. The goal is to turn X-inspired manipulation patterns into funny, character-driven Banny Studio episodes without mixing in Split & Peel football defaults.

## Source Stack

| Source | Use For | Output |
|---|---|---|
| X trends/posts | zeitgeist, language, manipulation patterns | fictionalized idea seeds |
| Producer brief | approved story target and constraints | episode mandate |
| Show bible | character voice, moral line, proof concepts | story guardrails |
| Episode memory | callbacks and avoided repeats | continuity |
| Production learnings | asset limits and pacing improvements | build defaults |

X is inspiration, not verification. If a real claim matters, verify it outside the episode or fictionalize it.

## Brainstorming Order

### 1. Identify The Manipulation Pattern

Write one sentence:

```text
This episode is about <manipulation pattern> causing <ordinary-person consequence>.
```

Examples:

- This episode is about a quietly edited school record causing a student to lose an award.
- This episode is about synthetic receipts making a fake apology look official.
- This episode is about a clipped video turning a boring committee meeting into a scandal.

### 2. Define The Moral Boundary

Name exactly what proof can and cannot show.

```text
The proof can show <integrity/timing/origin/change>. It cannot show <truth/intent/moral innocence>.
```

### 3. Run The Character Engines

Perry prompts:

- What original does he need?
- Which timeline detail does everyone else ignore?
- Where does his precision become funny?
- What shortcut is he tempted to take?

Fauxnana prompts:

- What prettier version of reality does she sell?
- What "-inator" did she build?
- Why does her argument sound appealing?
- What makes her scheme visually absurd?

Relationship prompts:

- Where does Fauxnana almost persuade Perry?
- Where does Perry puncture her glamour with one dry fact?
- Where does she admire his method despite herself?

### 4. Cartoon The Proof

Use this ladder:

```text
real manipulation -> exaggerated interpretation -> impossible machine/object -> public consequence -> proof-based reveal -> joke
```

### 5. Build A Premise Card

Every idea should use this shape:

```md
## <Title>

Inspiration source:
Manipulation pattern:
Ordinary-person consequence:
Fauxnana scheme:
Perry challenge:
Proof mechanism:
Moral boundary:
Visual escalation:
Best banter:
Final button:
Production notes:
```

### 6. Pick Winners

Score each idea 1 to 5:

- manipulation clarity
- Perry/Fauxnana specificity
- visual escalation
- proof concept clarity
- production feasibility

Do not script an idea until the manipulation pattern, proof mechanism, and final button are clear.

## Episode Script Rules

Target 6 to 10 spoken lines for a 60 second episode and 10 to 16 lines for a 120 second episode.

Dialogue rules:

- Perry is precise, dry, principled, and occasionally exasperated.
- Fauxnana is lush, teasing, theatrical, and intellectually persuasive.
- The episode must be funny before it is educational.
- The proof mechanism should appear naturally inside the plot.
- Avoid direct instruction like "Here is why provenance matters."

## Memory Workflow

Before brainstorming, read recent `memory/proof-patrol/*.json` when available.

After each episode, capture:

- what shipped
- manipulation pattern used
- proof concept used
- best Perry line
- best Fauxnana line
- strongest visual gag
- repeated joke to avoid
- useful callback
- production issue
